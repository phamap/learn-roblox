## Requirements
### Requirement: Публикация зеркала на Surge
Сайт SHALL автоматически собираться и публиковаться на `learn-roblox.surge.sh` при push в основную ветку репозитория, параллельно с существующим деплоем на GitHub Pages.

#### Scenario: Деплой при пуше контента
- **WHEN** автор пушит правку в `main`
- **THEN** CI собирает сайт с `SITE_BASE=/` и публикует обновлённую версию на `learn-roblox.surge.sh` без ручных действий

#### Scenario: Независимость зеркала от основного деплоя
- **WHEN** деплой на GitHub Pages падает или выполняется повторно
- **THEN** это не влияет на публикацию зеркала (отдельные workflow)

### Requirement: Фиксированный адрес зеркала
Зеркало SHALL публиковаться под фиксированным доменом `learn-roblox.surge.sh` (адрес не меняется между релизами).

#### Scenario: Адрес стабилен между релизами
- **WHEN** выполнено несколько последовательных деплоев
- **THEN** сайт доступен по одному и тому же адресу

### Requirement: Документация адресов
README SHALL содержать оба публичных адреса сайта (GitHub Pages — каноничный, Surge — зеркало) и предупреждение, что прогресс чекбоксов хранится отдельно для каждого адреса.

#### Scenario: Пользователь находит зеркало
- **WHEN** пользователь читает README репозитория
- **THEN** ему известны оба адреса курса и особенность хранения прогресса
