# progress-tracking Specification

## Purpose
Интерактивность курса: кликабельные чекбоксы шагов с сохранением прогресса в браузере (localStorage через единый модуль progress.ts) и индикаторы прогресса по фазам.
## Requirements
### Requirement: Интерактивные чекбоксы шагов
Чекбоксы шагов (`- [ ]` / `- [x]`) в отрендеренных гайдах фаз SHALL быть кликабельными. Состояние чекбокса SHALL сохраняться между визитами.

#### Scenario: Отметка шага
- **WHEN** пользователь кликает по неотмеченному чекбоксу шага
- **THEN** чекбокс становится отмеченным, и состояние сохраняется после перезагрузки страницы

#### Scenario: Снятие отметки
- **WHEN** пользователь кликает по отмеченному чекбоксу шага
- **THEN** чекбокс становится неотмеченным, и состояние сохраняется после перезагрузки страницы

### Requirement: Стабильные идентификаторы шагов
Каждый шаг SHALL иметь стабильный идентификатор вида `<slug-файла>:step-<N>`, где N — порядковый номер шага в файле. Идентификаторы MUST NOT содержать кириллицу.

#### Scenario: Прогресс переживает перезапуск браузера
- **WHEN** пользователь отметил шаги и вернулся через несколько дней в том же браузере
- **THEN** все ранее отмеченные шаги отображаются отмеченными

### Requirement: Хранение прогресса через единый модуль
Доступ к данным прогресса SHALL осуществляться только через модуль `progress.ts` (чтение, переключение, подписка на изменения). Реализация хранилища (localStorage) MUST NOT использоваться напрямую в компонентах.

#### Scenario: Изоляция хранилища
- **WHEN** просматривается клиентский код компонентов
- **THEN** обращения к localStorage присутствуют только внутри `progress.ts`

### Requirement: Отображение прогресса
На главной странице для каждой фазы и на странице каждой фазы SHALL отображаться индикатор прогресса («N/M шагов»), пересчитывающийся при изменении чекбоксов.

#### Scenario: Прогресс-бар обновляется
- **WHEN** пользователь отмечает или снимает отметку шага
- **THEN** индикатор прогресса на текущей странице обновляется без перезагрузки

#### Scenario: Прогресс по фазам на главной
- **WHEN** пользователь открывает главную страницу
- **THEN** рядом с каждой фазой отображается её прогресс («выполнено/всего шагов»)
