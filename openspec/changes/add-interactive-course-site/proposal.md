## Why

Курс по Roblox-разработке существует только как набор markdown-файлов — им неудобно пользоваться: нет навигации между фазами, подсветки кода и способа отслеживать свой прогресс. Превращение курса в статический сайт делает его доступным любому по ссылке и даёт автору трекинг прогресса, при этом markdown остаётся единственным источником контента.

## What Changes

- Добавляется статический сайт на Astro, который рендерит существующие md-файлы (план, 10 фаз, 2 шпаргалки) с подсветкой Luau
- Чекбоксы шагов в гайдах становятся интерактивными; прогресс сохраняется в localStorage браузера
- На главной странице (план курса) и в каждой фазе отображается прогресс-бар («5/12 шагов»)
- Существующие md-файлы переезжают из корня репозитория в `src/content/` (**BREAKING**: старые пути `phases/*.md`, `lua-shpargalka.md`, `roblox-shpargalka.md` перестанут работать; ссылки внутри md обновляются)
- Репозиторий становится публичным; добавляется CI-деплой на GitHub Pages через GitHub Actions (push → автосборка → публикация)
- README переписывается: из «лица курса» в техническую документацию репозитория

Вне скоупа MVP: аккаунты и серверный прогресс, квизы, пошаговый режим, миграция контента в JSON. Эти направления возможны в будущем — архитектура оставляет точки апгрейда.

## Capabilities

### New Capabilities

- `site-content-rendering`: рендеринг md-контента курса в статический сайт — Content Collections для плана, фаз и шпаргалок, подсветка Luau, навигация prev/next между фазами
- `progress-tracking`: интерактивные чекбоксы шагов с сохранением прогресса в localStorage через единый модуль progress.ts, стабильные ID шагов вида `<файл>:step-<N>`, прогресс-бары на плане и в фазах
- `site-deployment`: сборка и публикация сайта через GitHub Actions → GitHub Pages при push в основную ветку

### Modified Capabilities

_(нет — существующие спецификации guide-code-correctness, guide-plan-consistency, guide-progression-safety касаются содержания гайдов и не меняются; переезд файлов не влияет на их требования)_

## Impact

- **Структура репозитория**: корень очищается от md-файлов курса, добавляются конфиги Astro (`astro.config.mjs`, `package.json`), `src/`, `.github/workflows/deploy.yml`
- **Существующие файлы**: `roblox-learning-plan.md`, `phases/*.md`, шпаргалки переезжают в `src/content/`; внутренние ссылки между ними обновляются на новые пути
- **Зависимости проекта**: единственная новая зависимость — `astro`; никаких UI-фреймворков (интерактивность на vanilla TS)
- **CI/CD**: новый workflow GitHub Actions; билд выполняется на серверах GitHub, локальный билд нужен только для разработки
- **Хостинг**: GitHub Pages, публичный репозиторий — без затрат
