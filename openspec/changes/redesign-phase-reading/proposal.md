# Redesign: навигация и ориентация внутри фазы (чтение)

## Why

Фазы курса — это длинные markdown-документы (от 5 до 8 заголовков `## Шаг N`, 300+
строк), которые рендерятся как одна непрерывная простыня `<article>`. Цвета и шрифты
(тема Solarized Light) устраивают, но структура пугает: при открытии страницы не видно
«карты» фазы, непонятно, где находишься в процессе чтения, и нет ощущения движения —
из-за чего пропадает желание заниматься. Существующий прогресс-бар привязан к чек-листу
в самом низу страницы и не показывается по ходу чтения. Нужна ориентация поверх
существующего контента: боковой rail по шагам + sticky-блок с индикатором чтения.

## What Changes

- На страницах фаз (`/phases/*`) появляется **sticky-блок сверху**, объединяющий
  шапку сайта и индикатор чтения фазы: «Фаза N · Шаг K/M» + полоса заполнения,
  отражающая **% прокрутки** статьи (scroll-driven).
- На десктопе (≥900px) добавляется **боковой rail** со списком шагов фазы
  (`## Шаг N`): номер + заголовок, кликабелен, текущий шаг подсвечен через scroll-spy.
- На мобильных (<900px) rail скрывается, а его содержимое доступно через тот же
  sticky-блок в виде выпадающего списка (`▾`).
- Rail генерируется **на сервере** из заголовков `## Шаг N` markdown-файла фазы —
  содержимое `.md` не меняется.
- Нижний чек-лист «Самопроверка X/N» и его прогресс-бар остаются как есть: это
  отдельный счётчик **завершения** фазы, не конфликтующий с навигационным «Шаг K/M».

## Capabilities

### New Capabilities

- `phase-reading-navigation`: ориентация и навигация внутри страницы фазы — sticky-блок
  с индикатором чтения, боковой rail по шагам с подсветкой текущего шага, мобильный
  выпадающий аналог rail; всё поверх существующего рендера контента без правки `.md`.

### Modified Capabilities

- `site-content-rendering`: на страницах фаз меняется обёртка контента (PhaseLayout) —
  добавляются sticky-блок и rail; типографика/цвета не затрагиваются.

## Impact

- `src/layouts/PhaseLayout.astro` — разметка rail + sticky-блока, приём пропа `steps`.
- `src/pages/phases/[slug].astro` — парсинг `## Шаг N` из `phase.body`, передача `steps` в Layout.
- `src/layouts/BaseLayout.astro` — стили sticky-блока, двухколоночной сетки (rail+контент),
  мобильного сворачивания, `scroll-margin-top`; клиентский скрипт scroll-spy + scroll-%.
- `src/content/phases/*.md` — **не меняются**.
- `src/lib/progress.ts` — **не меняется** (только потребление, если потребуется для состояний).
