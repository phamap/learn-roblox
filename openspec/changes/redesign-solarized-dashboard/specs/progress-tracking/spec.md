# progress-tracking Specification (Delta)

## ADDED Requirements

### Requirement: Общий прогресс курса на главной
На главной странице SHALL отображаться агрегированный индикатор общего прогресса по курсу («N/M шагов» + прогресс-бар), вычисленный как сумма выполненных шагов всех фаз против суммы всех шагов.

#### Scenario: Отображение общего прогресса
- **WHEN** пользователь открывает главную страницу
- **THEN** видит общий индикатор прогресса, где N — суммарно отмеченные шаги всех фаз, M — суммарное количество шагов

#### Scenario: Пересчёт при возврате на главную
- **WHEN** пользователь отметил шаги на странице фазы и вернулся на главную
- **THEN** общий индикатор прогресса отражает актуальное состояние
