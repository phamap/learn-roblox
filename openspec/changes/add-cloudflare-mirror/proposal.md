## Why

GitHub Pages недоступен из сетей ряда российских провайдеров (домен `*.github.io` блокируется), поэтому автор курса не может открывать собственный сайт без VPN. Зеркало на Cloudflare Pages даёт второй адрес, доступный из России, без отказа от существующего деплоя.

## What Changes

- Сайт дополнительно публикуется на Cloudflare Pages по адресу `*.pages.dev`, подключённому к тому же git-репозиторию
- Base path сайта становится настраиваемым через переменную окружения: на GitHub Pages остаётся `/learn-roblox/`, на Cloudflare сайт отдаётся от корня
- Деплой на обе площадки происходит автоматически при push в `main` (GitHub Actions + встроенный CI Cloudflare)
- README дополняется информацией о зеркале

Вне скоупа: свой домен, синхронизация прогресса между площадками, изменение внешнего вида сайта.

## Impact

- **Код**: `astro.config.mjs` — base path из переменной окружения (умолчание прежнее); других изменений кода нет
