## Context

Текущая структура проекта:
- `lua-shpargalka.md` (217 строк) — Lua-синтаксис для JS-программистов
- `robux-shpargalka.md` (211 строк) — Lua + Roblox API (дублирует ~60% контента двух других файлов)
- `roblox-shpargalka.md` (386 строк) — полная шпаргалка по Obby
- `roblox-learning-plan.md` (153 строки) — 8-фазный план обучения

Файл `robux-shpargalka.md` не ссылается в плане обучения и содержит контент, который уже есть в двух других файлах.

## Goals / Non-Goals

**Goals:**
- Устранить дублирование контента
- Сохранить полезный уникальный контент из удаляемого файла
- Исправить найденные ошибки
- Расширить план обучения недостающими темами
- Сохранить читаемость файлов (не более ~450 строк каждый)

**Non-Goals:**
- Полная переработка контента шпаргалок
- Добавление нового учебного материала (только реорганизация)
- Изменение формата файлов (оставляем markdown)

## Decisions

### 1. Удалить robux-shpargalka.md, перенести уникальный контент

**Решение:** Слить уникальные секции из `robux-shpargalka.md` в `roblox-shpargalka.md`, затем удалить файл.

**Альтернативы:**
- Оставить три файла — отвергнуто: дублирование усложняет поддержку
- Слить все в один файл — отвергнуто: файл превысит 600 строк
- Переименовать robux- в промежуточный — отвергнуто: не решает проблему дублирования

**Обоснование:** Два файла (Lua-синтаксис + Roblox API) покрывают всё необходимое с хорошей прогрессией.

### 2. Исправить ошибки при слиянии

**Решение:** Исправить опечатку в lua-shpargalka.md (строка 135: "с较но" → "серьёзно") и неточный совет про Touched в roblox-shpargalka.md.

**Обоснование:** Ошибки снижают доверие к материалу.

### 3. Расширить план обучения

**Решение:** Добавить 2-3 новые фазы в `roblox-learning-plan.md`:
- Фаза 5.5: RemoteEvent + клиент-сервер взаимодействие
- Фаза 7.5: Оптимизация производительности
- Фаза 8.5: CI/CD с Rojo (опционально)

**Обоснование:** Без RemoteEvent невозможно сделать реальную multiplayer-игру. Оптимизация и CI/CD — стандарт продакшн-процесса.

### 4. Порядок выполнения

**Решение:** 
1. Исправить ошибки в существующих файлах
2. Скопировать уникальный контент из robux- в roblox-shpargalka.md
3. Обновить ссылки в roblox-learning-plan.md
4. Удалить robux-shpargalka.md
5. Расширить roblox-learning-plan.md новыми фазами

**Обоснование:** Минимальный риск потери данных — сначала копируем, потом удаляем.

## Risks / Trade-offs

| Риск | Митигация |
|------|-----------|
| Потеря контента при удалении файла | Уникальный контент перенесён в roblox-shpargalka.md до удаления |
| Нарушение ссылок | Все ссылки в плане обновлены до удаления |
| Увеличение roblox-shpargalka.md | Контролируем размер: уникальный контент из robux- добавит ~30 строк |
| Сломанная нумерация секций | Проверить после слияния |
