## Решение (уточнено в ходе реализации)

Изначальный план — совпадение *колонок чтения* (860/820px) — был изменён по запросу:
главная страница должна совпадать по ширине со страницей фазы. Выбран вариант
«Главная=1120»: общий блок на всех страницах = `--page-width` (1120px). Текст главной
становится ~1080px (шире колонки чтения фазы ~820px). Колонка чтения фазы по-прежнему
ограничена `--content-width`, rail не сужает её.
