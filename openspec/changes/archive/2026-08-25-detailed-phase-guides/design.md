## Context

План обучения (`roblox-learning-plan.md`) разбит на 10 фаз с чеклистами. Каждая фаза ссылается на шпаргалки (`lua-shpargalka.md`, `roblox-shpargalka.md`) и внешние ресурсы. Проблема: чтобы выполнить один шаг, нужно переключаться между несколькими документами.

Существует прототип Фазы 1 (`phases/phase-1-studio.md`) — формат проверен, его берём за основу.

## Goals / Non-Goals

**Goals:**
- Каждый файл фазы — самодостаточный туториал: открыл, прочитал, сделал, получил результат
- Готовые сниппеты кода копируй-вставляй (не обрезанные, не псевдокод)
- Таблица типичных ошибок в каждой фазе
- Чеклист завершения фазы
- Навигация между фазами (ссылки на предыдущую/следующую)

**Non-Goals:**
- Не менять структуру `roblox-learning-plan.md` (только добавить ссылки)
- Не изменять шпаргалки (`lua-shpargalka.md`, `roblox-shpargalka.md`)
- Не делать видео-туториалы или интерактивные упражнения
- Не переписывать документацию Roblox — только практические инструкции

## Decisions

### 1. Формат файла: один Markdown на фазу

**Решение:** каждый файл = `phases/phase-{номер}-{название}.md`

**Альтернативы considered:**
- Один общий файл — отвергнут: слишком длинный, сложно навигировать
- Разбивка на подшаги (отдельные файлы на каждый шаг) — отвергнут: слишком много файлов, сложно ориентироваться

**Почему:** один файл на фазу = один контекст. Не нужно открывать/закрывать файлы во время выполнения.

### 2. Структура файла: 7 блоков

```
1. Зачем это нужно (цель фазы)
2. Что сможешь после (результат)
3. Шаги (пошагово с кодом)
4. Мини-проект (закрепление)
5. Типичные ошибки (таблица)
6. Чеклист завершения
7. Ссылки для углубления (необязательные)
```

**Почему:** сначала мотивация → потом действия → потом практика → потом troubleshooting. Линейный поток, без возвратов.

### 3. Код: English, комментарии: Russian

Скрипты на Lua как в Roblox (английские ключевые слова, API). Комментарии в коде на русском для понимания.

### 4. Ссылки: в конце файла, не в теле

Ссылки на доки, DevForum, видео — в отдельном блоке в конце. В теле шагов — только готовый код и инструкции. Исключение: ссылки на шпаргалки, где нужно прочитать раздел перед выполнением шага.

### 5. Прототип как референс

`phases/phase-1-studio.md` уже создан. Остальные фазы пишутся по тому же шаблону. При расхождениях — приводим к единому формату.

## Risks / Trade-offs

| Риск | Митигация |
|------|-----------|
| Файлы станут слишком длинными (1000+ строк) | Ограничивать теорию, фокус на практике. Теория — в шпаргалках. |
| Код устареет при обновлении Roblox API | Использовать стабильные API (Touched, TweenService). Добавить дату последней проверки. |
| Дублирование между шпаргалками и фазами | Шпаргалки — справочник. Фазы — туториал. Шпаргалки ссылаются из фаз, не дублируют. |
| Пользователь застрянет на шаге | Таблица ошибок + чеклист. Если не помогло — вернуться к шпаргалке. |
