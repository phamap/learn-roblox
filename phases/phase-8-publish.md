# Фаза 8: Публикация — выложи игру!

**Цель:** опубликовать игру в каталоге Roblox, поделиться с друзьями.
**Итог:** опубликованная игра, доступная всем игрокам Roblox.
**Время:** 1-2 часа.
**Предыдущая фаза:** [Фаза 7.5: Оптимизация производительности](./phase-7-5-optimization.md)

## Что ты сможешь после этой фазы

- Опубликовать игру в каталоге Roblox
- Настроить описание, иконку, настройки
- Пригласить друзей
- Понимать настройки приватности

---

## Шаг 1: Подготовка к публикации

### 1.1 Финальный чеклист

Перед публикацией проверь:

- [ ] Игра работает без ошибок (нет красных сообщений в Output)
- [ ] Все Level'ы проходимы
- [ ] Чекпоинты работают
- [ ] GUI обновляется
- [ ] Звуки играют
- [ ] DataStore сохраняет данные
- [ ] FPS стабильный (>30)

### 1.2 Сохрани проект

**File** → **Save to Roblox As...** — сохрани проект в облаке Roblox.

---

## Шаг 2: Публикация

### 2.1 Открой Game Settings

1. Наверху нажми **Home** (или **File**)
2. Нажми **Game Settings**
3. Перейди на вкладку **Security**

### 2.2 Настрой Game Settings

#### Вкладка: Basic Info

| Поле | Значение |
|------|----------|
| **Name** | `My Obby` (или своё название) |
| **Description** | Описание игры для каталога |
| **Creator** | Твой никнейм |

#### Вкладка: Security

| Настройка | Значение |
|-----------|----------|
| **Enable Studio Access to API Services** | ✅ |
| **Allow HTTP Requests** | ❌ (если не нужно) |

#### Вкладка: Permissions

| Настройка | Значение |
|-----------|----------|
| **Playability** | Public (публичная) или Private (только ты) |
| **Device Targets** | Computer, Phone, Tablet, Console |

### 2.3 Опубликуй

1. Нажми **Save** в Game Settings
2. Наверху нажми **File** → **Publish to Roblox**
3. Подтверди публикацию

---

## Шаг 3: Настройки каталога

### 3.1 Открой страницу игры

1. Открой браузер
2. Зайди на https://create.roblox.com
3. Найди свою игру
4. Нажми **Configure**

### 3.2 Настрой описание

| Поле | Рекомендация |
|------|-------------|
| **Name** | Короткое, запоминающееся название |
| **Description** | Что делает игра, особенности |
| **Genre** | Adventure, Obby |
| **Devices** | Компьютер, Телефон, Планшет |

### 3.3 Загрузи иконку

1. В **Configure** → **General**
2. Нажми **Change** рядом с иконкой
3. Загрузи картинку 512x512 пикселей

> Иконка — первое что видят игроки. Сделай яркой и понятной.

### 3.4 Загрузи Thumbnail (скриншот)

1. В **Configure** → **Thumbnails**
2. Нажми **Add** и загрузи скриншот
3. Рекомендованный размер: 1920x1080

---

## Шаг 4: Тестирование в опубликованной игре

### 4.1 Запусти из каталога

1. Открой страницу игры в браузере
2. Нажми **Play** (зелёная кнопка)
3. Игра откроется в Roblox Player

### 4.2 Проверь всё

- [ ] Загрузка работает
- [ ] Все скрипты функционируют
- [ ] DataStore сохраняет данные
- [ ] FPS стабильный
- [ ] Нет ошибок в Output

### 4.3 Исправь ошибки

Если что-то не работает:
1. Вернись в Studio
2. Исправь проблему
3. Сохрани (**File** → **Save to Roblox**)
4. Опубликуй заново (**File** → **Publish to Roblox**)

---

## Шаг 5: Приглашение друзей

### 5.1 Ссылка на игру

Ссылка формируется автоматически:
```
https://www.roblox.com/games/ЧИСЛО/НАЗВАНИЕ
```

### 5.2 Приглашение

1. Открой страницу игры
2. Нажми **Share** (поделиться)
3. Скопируй ссылку
4. Отправь друзьям

### 5.3 Приватность

| Настройка | Что делает |
|-----------|-----------|
| **Public** | Все могут играть |
| **Private** | Только ты и приглашённые |
| **Friends** | Только друзья |

---

## Шаг 6: Обновления

### 6.1 Как обновить игру

1. Открой проект в Studio
2. Внеси изменения
3. **File** → **Save to Roblox**
4. **File** → **Publish to Roblox**

> Игроки автоматически получат обновление при следующем входе.

### 6.2 Версионирование

Рекомендую добавить версию в описание:
```
v1.0 — Первая публикация
v1.1 — Исправлен баг с чекпоинтами
v1.2 — Добавлены новые уровни
```

## Типичные ошибки

| Проблема | Причина | Решение |
|----------|---------|---------|
| "Publish failed" | Нет прав на создание | Проверь аккаунт |
| Игра не загружается | Ошибка в скрипте | Проверь Output в Studio |
| DataStore не работает | API Services выключены | Включи в Game Settings |
| Иконка не отображается | Размер неправильный | 512x512 пикселей |
| Игра медленная на телефоне | Слишком тяжёлая | Оптимизируй (Фаза 7.5) |
| Нет игроков | Плохое описание/иконка | Улучши описание, добавь thumbnail |
