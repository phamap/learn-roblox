# Фаза 1: Знакомство с Roblox Studio

**Цель:** ориентироваться в интерфейсе, создавать объекты, писать простейшие скрипты.
**Итог:** сцена с разноцветными платформами и скрипт, который окрашивает платформу при касании.
**Время:** 3-5 часов (1-2 недели по 1-2 часа в день).

---

## Что ты сможешь после этой фазы

- Открыть Studio и ориентироваться в панелях
- Создавать и настраивать 3D-объекты (Part'ы)
- Запускать игру и тестировать её
- Писать простейшие скрипты на Lua
- Использовать Command Bar для быстрых изменений

---

## Шаг 0: Установка Roblox Studio

Если Studio ещё не установлена:

1. Зайди на https://create.roblox.com
2. Нажми **"Start Creating"** или **"Download Studio"**
3. Запусти установщик, следуй инструкциям
4. Открой Studio, войди через свой аккаунт Roblox

> Если Studio уже стоит — просто открой её.

## Шаг 1: Знакомство с интерфейсом

Открой Studio. Ты увидишь главную панель с вариантами создать новый проект. Выбери **"Baseplate"** — это пустой мир с одной большой платформой.

### Разверни все панели

Если какая-то панель не видна:

1. Наверху нажми **View** (Вид)
2. Нажми **Explorer** — появится панель со списком объектов
3. Нажми **Properties** — появятся свойства выбранного объекта
4. Нажми **Output** — появится консоль для вывода

> **Вывод (Output)** — твой лучший друг. Сюда пишет `print()`, сюда выводятся ошибки. Держи его открытым всегда.

### Изучи Explorer

В панели **Explorer** (слева) ты видишь дерево объектов:

```

└── StarterGui         ← сюда будешь кидать интерфейс
```

**Попробуй:** кликни по `Baseplate` в Explorer. Справа в Properties появятся его свойства (Size, Color, Position и т.д.).

## Шаг 2: Создаём и настраиваем Part

### 2.1 Создай Part

1. В Explorer кликни правой кнопкой по **Workspace**
2. Выбери **Insert Object** → **Part**

Появится серый кубик на платформе.

### 2.2 Настрой его свойства

Выдели Part в Explorer и измени в Properties:

| Свойство | Значение | Что делает |
|----------|----------|------------|
| **Size** | `4, 1, 4` | Размер (ширина, высота, глубина) |
| **Position** | `0, 5, 0` | Где стоит (x, y, z). Y=5 значит 5 стёп над платформой |
| **Anchored** | ✅ включено | Часть стоит на месте, не падает |
| **Color** | любая яркая | Цвет части |
| **Material** | `Neon` | Материал (Neon светится) |

> **Anchored** — ключевой момент. Без него Part падает вниз под действием гравитации. Для платформ всегда включай Anchored.

### 2.3 Запусти и посмотри результат

Наверху нажми **Play** (или клавиша F5).

Ты увидишь свою часть в мире. Погоняй персонажа вокруг неё.

Нажми **Stop** (или Esc).

## Шаг 3: Experiment с Command Bar

**Command Bar** — это консоль, где можно выполнять Lua-код прямо в реальном времени. Идеально для экспериментов.

### Открой Command Bar

**View** → **Command Bar** (внизу появится узкая строка).

### Попробуй эти команды

Копируй по одной и нажимай Enter:

**Изменить цвет выделенного Part:**
```lua
workspace.Part.Color = Color3.fromRGB(255, 0, 0)
```

**Изменить размер:**
```lua
workspace.Part.Size = Vector3.new(8, 2, 8)
```

**Сделать невидимым:**
```lua
workspace.Part.Transparency = 1
```

**Сделать видимым снова:**
```lua
workspace.Part.Transparency = 0
```

**Поднять на 20 стёп вверх:**
```lua
workspace.Part.Position = Vector3.new(0, 25, 0)
```

**Вернуть на место:**
```lua
workspace.Part.Position = Vector3.new(0, 5, 0)
```

### Что мы только что сделали

Ты только что программно управлял 3D-объектом. Те же свойства (Size, Color, Position, Transparency) ты будешь менять в скриптах.

## Шаг 4: Первый скрипт — Hello Roblox

### 4.1 Создай скрипт

1. В Explorer кликни правой кнопкой по **Workspace**
2. Выбери **Insert Object** → **Script**

> **Script** — это серверный скрипт. Он выполняется на сервере. Для начала используем только Script (не LocalScript).

### 4.2 Напиши код

Открой скрипт (дважды кликни). Удали всё что там и напиши:

```lua
print("Hello Roblox!")
```

### 4.3 Запусти

Нажми **Play** (F5).

Посмотри на **Output** (внизу). Ты увидишь:

```
Hello Roblox!
```

🎉 Поздравляю! Ты написал свой первый скрипт в Roblox.

### 4.4 Переименуй скрипт

Дважды кликни по `Script` в Explorer и переименуй в `HelloScript`. Так легче ориентироваться когда скриптов станет много.

## Шаг 5: Скрипт меняет Part по времени

### 5.1 Создай Part для скрипта

1. Создай новый Part в Workspace (правой кнопкой → Insert Object → Part)
2. Назови его `ColorPart` (дважды кликни по имени в Explorer)
3. Поставь **Anchored = true**

### 5.2 Создай скрипт внутри Part

1. Кликни правой кнопкой по **ColorPart** в Explorer
2. Insert Object → **Script**

### 5.3 Напиши код

```lua
-- Скрипт внутри ColorPart
local part = script.Parent  -- script.Parent = объект, в котором лежит скрипт (ColorPart)

-- Ждём 2 секунды, потом меняем цвет
task.wait(2)
part.Color = Color3.fromRGB(255, 0, 0)  -- красный

task.wait(2)
part.Color = Color3.fromRGB(0, 255, 0)  -- зелёный

task.wait(2)
part.Color = Color3.fromRGB(0, 0, 255)  -- синий

print("Цвета поменялись!")
```

### 5.4 Запусти Play

Ты увидишь: через 2 секунды Part станет красным, потом зелёным, потом синим.

> **`script.Parent`** — это объект, внутри которого лежит скрипт. Очень частый паттерн: скрипт живёт внутри Part'а и управляет им.

> **`task.wait(секунды)`** — пауза. Как `setTimeout`, но синхронный.

## Шаг 6: Мини-проект — сцена с касанием

Теперь соберём всё вместе. Мы сделаем:
- 5 разноцветных Part'ов
- Скрипт, который окрашивает Part в красный когда игрок его касается

### 6.1 Создай 5 Part'ов

Создай 5 Part'ов в Workspace. Настрой каждый:

| Название | Position | Color | Anchored |
|----------|----------|-------|----------|
| `Platform1` | `-8, 3, 0` | Синий | ✅ |
| `Platform2` | `-4, 3, 0` | Зелёный | ✅ |
| `Platform3` | `0, 3, 0` | Жёлтый | ✅ |
| `Platform4` | `4, 3, 0` | Белый | ✅ |
| `Platform5` | `8, 3, 0` | Фиолетовый | ✅ |

Все: Size = `4, 1, 4`

> **Совет:** создай один Part, настрой его, потом скопируй (Ctrl+D в Explorer) и измени Position и Color. Так быстрее.

### 6.2 Создай скрипт для касания

1. Кликни правой кнопкой по **Workspace** (не по Part!)
2. Insert Object → **Script**
3. Назови его `TouchColorScript`
4. Напиши:

```lua
-- TouchColorScript в Workspace
-- Окрашивает Part в красный при касании

local function onTouched(hit)
    -- hit — это объект, которым коснулись
    -- Нам нужен Humanoid чтобы понять, что это игрок
    local character = hit.Parent
    local humanoid = character:FindFirstChild("Humanoid")

    if humanoid then
        -- Это игрок! Меняем цвет
        local part = hit  -- та часть, которой коснулись
        part.Color = Color3.fromRGB(255, 0, 0)
        print(part.Name .. " стал красным!")
    end
end

-- Подключаем ко всем Part'ам с именем Platform*
for _, part in pairs(workspace:GetChildren()) do
    if part:IsA("BasePart") and part.Name:find("Platform") then
        part.Touched:Connect(onTouched)
        print("Следим за " .. part.Name)
    end
end
```

### 6.3 Запусти Play

Подойди к платформам и коснись их. Каждая станет красной когда ты её коснёшься.

### Что здесь происходит

```
┌─────────────────────────────────────────────────────────┐
│                    ЧТО ДЕЛАЕТ СКРИПТ                    │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  1. Находит все Part'ы с именем "Platform*"             │
│  2. Подключается к событию Touched каждого              │
│  3. Когда кто-то касается Part:                         │
│     ├─ Проверяет: это Humanoid (игрок)?                 │
│     ├─ Если да → меняет Color на красный                │
│     └─ Если нет (упал кубик) → ничего не делает      │
│                                                         │
│  Ключевые концепции:                                    │
│  • script.Parent — объект-владелец                      │
│  • :Touched:Connect(func) — подписка на событие         │
│  • hit.Parent — персонаж, частью которого был hit       │
│  • :FindFirstChild("Humanoid") — ищет компонент        │
│  • :IsA("BasePart") — проверка типа объекта            │
│  • workspace:GetChildren() — все прямые дочерние объекты│
│  • for _, item in pairs(table) do — итерация            │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

## Шаг 7: Закрепление — измени мини-проект

Сделай эти изменения сам (без подсказок, используй то что выучил):

1. **Другой цвет:** измени скрипт чтобы Part'ы становились не красным, а зелёным
2. **Случайный цвет:** заставь Part'ы меняться на случайный цвет при касании
3. **Сброс:** через 3 секунды после касания Part возвращается к исходному цвету

> Подсказка для 3: тебе понадобится сохранять оригинальный цвет и использовать `task.wait()`.

## Типичные ошибки

| Ошибка | Причина | Решение |
|--------|---------|---------|
| "Part is not a valid member of Workspace" | Опечатка в имени | Проверь регистр: `Part` vs `part` — это разные имена |
| Part падает вниз | Anchored = false | Включи Anchored в Properties |
| Скрипт не работает | Тип скрипта не тот | Убедись что это **Script**, а не LocalScript |
| Output пустой | Play ещё не нажат | Нажми Play, print() работает только во время игры |
| "attempt to index nil" | Объект не найден | Добавь `print()` перед проблемной строкой, проверь имя |
| Скрипт внутри Workspace не видит Part | Неправильный путь | Используй `workspace.PartName` или `script.Parent.PartName` |
