# Roblox Obby — план обучения

Учебные материалы по разработке игры-обби в Roblox Studio: план на 18–20 недель, детальные гайды по каждой фазе и шпаргалки-справочники.

**Подход:** учись на проекте — каждый этап завершается мини-проектом, а теория подаётся ровно в том объёме, который нужен для следующего шага.

**Итог:** рабочий Obby с чекпоинтами, сохранением прогресса, интерфейсом и звуками, опубликованный в Roblox.

---

```
│   ├── phase-6-datastore.md      # DataStore — сохранение данных
│   ├── phase-7-polish.md         # Полировка — звук, свет, декор
│   ├── phase-7-5-optimization.md # Оптимизация производительности
│   └── phase-8-publish.md        # Публикация игры

```

## Как пользоваться

1. Открой [roblox-learning-plan.md](./roblox-learning-plan.md) — это карта курса с чеклистами
2. Для каждой фазы переходи по ссылке на детальный гайд в `phases/`
3. Выполняй шаги последовательно в Roblox Studio — гайды написаны так, что все объекты и скрипты создаются до первого использования
4. Застрял на синтаксисе? Смотри шпаргалки — они сгруппированы по темам фаз
5. Отмечай пункты чеклистов в плане и двигайся дальше

## Что ты освоишь

- **Основы Studio:** Part'ы, свойства, Explorer, первый скрипт
- **Скриптинг:** события (`Touched`), debounce, Humanoid
- **Анимация:** TweenService, движущиеся платформы, EasingStyle
- **Игровая логика:** SpawnLocation, `player.RespawnLocation`, отслеживание прогресса на сервере
- **GUI:** ScreenGui, счётчики, экран смерти, leaderstats
- **Клиент-сервер:** RemoteEvent, модель безопасности Roblox
- **Данные:** DataStore, автосохранение, pcall
- **Полировка:** звуки, освещение, частицы, декорации
- **Оптимизация:** FPS, StreamingEnabled, Collision Groups
- **Публикация:** выкладка игры, сбор фидбека

## Требования

- [Roblox Studio](https://create.roblox.com/) (бесплатно)
- 5–10 часов в неделю
- Опыт программирования не требуется — всё объясняется с нуля
